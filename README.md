# 령령의 마리나라 제작실

령령과 대화하며 캐릭터·페르소나·로어북을 만들고, 필요한 부분을 수정해 Marinara 라이브러리에 저장하는 확장입니다.

**공개 버전: v2.0.0 · Marinara Engine v2.5.0에서 제작·호환 확인**

## 주요 기능

- 캐릭터·페르소나·로어북을 각각 독립된 제작실에서 작업합니다.
- 자유 제작, 기존 자료 참고, 기존 항목 편집을 지원합니다.
- 브리핑·최종본·부분 수정 요청을 RP방으로 보내고, 마지막 답변을 가져옵니다.
- 기존 캐릭터·페르소나·로어북 Entry와 외부 문서를 참고할 수 있습니다.
- 초안 임시 저장, 이전 결과 복원, JSON 저장·복사, 새 항목 등록과 원본 저장을 지원합니다.

## 설치 전 설정

1. Marinara 서버의 `.env`에서 `ENABLE_EXTERNAL_EXTENSIONS=true`로 설정합니다.
2. Marinara의 **설정 → 고급 설정 → 위험 구역(Danger Zone)**에서 **타사 확장 가져오기 허용(Allow third-party extension imports)**을 켭니다.
3. **부가기능(Addons) → 외부 확장(External Extensions)**을 엽니다.

서버 설정이 잠겨 있다면 서버 관리자에게 설정을 요청하세요. GitHub 확장 관리자로 설치하려면 해당 관리자가 먼저 설치되어 있어야 합니다.

## GitHub 확장 관리자로 설치

1. GitHub 확장 관리자에서 **확장 추가**를 누릅니다.
2. 저장소 주소에 아래 주소를 입력합니다.

   ```text
   https://github.com/you2-use/lingling-studio
   ```

3. **패키지 찾기**를 누릅니다.
4. 저장소 최상위의 **manifest.json**을 선택합니다.
5. 이름이 **령령의 마리나라 제작실**, 버전이 **2.0.0**인지 확인하고 설치합니다.
6. 설치된 확장의 코드와 **전체 페이지 접근** 권한을 검토한 뒤 실행을 승인하고 활성화합니다.

설치하는 사람의 GitHub 로그인이나 토큰은 필요하지 않습니다.

## ZIP으로 직접 설치

1. [확장 설치 ZIP 다운로드](https://github.com/you2-use/lingling-studio/releases/latest/download/lingling-studio.personal-extension.zip)를 누릅니다.
2. ZIP을 **풀지 않고**, Marinara의 **외부 확장 → 확장 파일 가져오기(Import Extension File)**에서 선택합니다.
3. 이름·버전·코드·권한을 확인하고 가져온 뒤 실행을 승인합니다.

GitHub 확장 관리자가 기본 가져오기 버튼을 숨겼다면 **확장 추가 → 파일에서**로 같은 ZIP을 선택하세요. GitHub의 **Source code (zip)**은 설치 파일이 아닙니다. ZIP으로 설치한 확장을 GitHub 관리자로 업데이트하려면 저장소를 별도로 연결해야 합니다.

## 령령 봇카드와 추가 이미지

- [령령 봇카드 다운로드 — CharacterCard.json](https://github.com/you2-use/lingling-studio/releases/latest/download/CharacterCard.json)
- [령령 추가 이미지 다운로드 — LinglingImage.zip](https://github.com/you2-use/lingling-studio/releases/latest/download/LinglingImage.zip)

봇카드는 Marinara의 캐릭터 가져오기로 등록하고 령령이 참여하는 RP방을 여세요. 카드에 들어 있는 내장 로어북도 함께 확인하세요. 이 카드는 이름이 `{{char}}`로 설정되어 있습니다. 연동에 사용하는 페르소나 이름은 `{{user}}`로 맞춰 사용하세요. 확장은 두 매크로를 원문 그대로 전달합니다.

추가 이미지 ZIP은 압축을 풀어 그림을 꺼내 사용하세요. 확장 설치 파일이 아니며 확장 파일 가져오기에 넣지 않습니다. 확장 업데이트만으로 기존 봇카드나 이미지를 교체하지 않습니다.

## 사용 방법

1. 령령이 참여하는 **RP방**을 엽니다.
2. 화면 **오른쪽 아래의 유령 버튼**에 마우스를 올리면 **령령의 제작실**이 표시됩니다. 버튼을 눌러 창을 엽니다. 버튼과 창은 끌어서 옮길 수 있습니다.
3. 창 왼쪽 위의 **사람·가면·책 아이콘**으로 캐릭터·페르소나·로어북 제작실을 선택합니다.
4. **1단계 준비**에서 자유 제작·기존 자료 참고·기존 항목 편집 중 작업 방식을 고르고 구상이나 참고 자료를 입력합니다. **령령에게 바로 요청**을 누릅니다. 기존 항목 편집은 원본을 선택해 편집 화면으로 이동합니다.
5. **2단계 제작**에서 령령과 대화하며 내용을 다듬고, 형식과 분량을 골라 **최종본 바로 요청**을 누릅니다. 답변 생성이 끝나면 **마지막 AI 답변 가져오기**를 누릅니다.
6. **3단계 편집**에서 항목을 직접 고치거나 **부분 수정 요청**을 보냅니다. **마지막 답변 가져오기** 또는 직접 붙여넣기로 수정 결과를 반영합니다.
7. **4단계 최종**에서 결과를 확인하고 새 항목으로 등록하거나 원본에 저장합니다. JSON 파일 저장과 전체 복사도 사용할 수 있습니다.

단계 탭은 넓은 창에서는 왼쪽, 좁은 창에서는 아래에 표시됩니다. 요청 제목 옆의 작은 아이콘으로 요청문을 RP 입력창에 넣거나 복사할 수 있습니다. 요청을 보내도 제작실 창은 유지되며, 오른쪽 위 **닫기** 버튼으로 닫습니다.

## 적용과 저장

| 기능 | 동작 |
| --- | --- |
| 답변 가져오기·직접 입력 | 제작실의 작업 초안에 반영합니다. 라이브러리 원본은 최종 저장 전까지 바뀌지 않습니다. |
| 새 항목 등록 | 새 캐릭터·페르소나·로어북을 만듭니다. 현재 방에서 사용할 항목을 자동으로 교체하지 않습니다. |
| 원본 캐릭터·페르소나에 저장 | 편집 모드에서 불러온 원본의 변경된 필드만 저장합니다. 같은 필드가 외부에서 변경되었다면 충돌을 확인합니다. |
| 원본 로어북에 저장 | 변경한 Entry와 추가·삭제·순서 변경을 반영합니다. 저장 도중 일부만 반영되었을 수 있다는 안내가 나오면 라이브러리 결과를 먼저 확인합니다. |
| 임시 저장 | 창 오른쪽 위의 저장 아이콘으로 선택한 제작실의 초안을 확장 저장소에 보관합니다. 라이브러리 등록과 별개입니다. |
| 초기화 | 선택한 제작실의 초안과 임시 저장 작업을 초기화합니다. 이미 라이브러리에 등록한 항목은 삭제하지 않습니다. |

제작실 전환 시 작업을 저장하며, 브라우저를 닫기 전에는 **임시 저장**하세요. 캐릭터·페르소나·로어북의 초안과 수정 이력은 서로 독립적입니다. 앱을 다시 열면 내부 참고 자료는 다시 선택해야 합니다.

**참고 자료 상시 주입**과 **현재 프롬프트·로어북 상시 주입**을 켜면 연결한 RP방의 생성 요청에 해당 내용을 추가합니다. 사용 중인 제작실과 연결된 방을 확인하고 필요한 동안만 켜세요. 이미 대화에 보낸 자료는 토글을 꺼도 대화 기록에 남습니다.

## 지원 형식과 제한

- 캐릭터는 제작실 필드 블록과 전용 최종본·부분 수정 형식, 페르소나는 이름·설명·성격·배경 이야기·외모·시나리오 필드를 지원합니다. 로어북은 제작실 전용 JSON 응답을 사용합니다.
- 마지막 답변 가져오기는 **현재 RP방에 저장된 마지막 메시지 1개**만 읽습니다. 마지막이 사용자 메시지·일반 대화·다른 제작실 결과라면 이전 답변을 찾아오지 않습니다. 생성 중이거나 응답이 잘렸다면 가져오기를 기다리거나 다시 요청하세요.
- 캐릭터 JSON은 Character Card v2 형식, 페르소나 JSON은 여섯 프롬프트 필드, 로어북 JSON은 Marinara 로어북 형식입니다. 페르소나의 아바타·색상·스탯까지 보관하려면 Marinara의 전체 내보내기를 사용하세요.
- 참고 캐릭터는 최대 3명, 참고 페르소나는 최대 3개입니다. 준비 화면에 표시되는 해당 항목을 선택할 수 있습니다.
- 외부 자료는 제작실마다 최대 5개, 본문은 자료당 60,000바이트·전체 110,000바이트입니다. 팬덤(Fandom) HTTPS 문서만 링크 불러오기를 지원합니다. 나무위키·픽시브 백과사전 등은 직접 붙여넣기를 사용하세요.
- 팬덤 수집은 로그인 없이 문서 본문을 읽습니다. 기존 본문이 있는 항목은 다시 불러오기로 덮어쓰지 않습니다. 새로 받으려면 해당 자료를 삭제한 뒤 불러오세요.
- 토큰 수는 로컬 추정치이며 실제 모델 사용량과 다를 수 있습니다. AI의 출력 형식이나 품질은 사용하는 모델에 따라 달라질 수 있습니다. 전용 번역 기능은 없으며 부분 수정 요청에 번역할 내용을 적을 수 있습니다.

## 권한과 데이터 처리

**전체 페이지 접근(`full_page_access`)** 권한은 Marinara 화면에 제작실을 표시하고 RP 입력창·현재 방·내부 API와 연동하기 위해 필요합니다.

초안과 참고 본문은 현재 Marinara의 확장 저장소에 보관합니다. 선택한 내부 자료와 마지막 메시지는 현재 Marinara 서버에서 읽으며, 라이브러리 저장은 저장 버튼을 누를 때 실행합니다. 상시 주입을 켠 자료와 사용자가 보낸 요청은 RP방의 AI 생성 입력에 포함되어, 그 방에 설정된 AI 서비스로 전달됩니다.

팬덤 링크 불러오기는 해당 공개 문서에 직접 읽기 요청을 보냅니다. 로그인 쿠키를 보내지 않고 그림·영상·웹페이지 코드를 실행하지 않습니다. 확장은 별도의 분석·번역·AI 서버를 사용하지 않습니다. 로컬 JSON 저장과 복사는 브라우저에서 처리합니다.

## 업데이트와 수정 기록

GitHub 확장 관리자에서 **업데이트 확인 → 업데이트 설치**를 사용하세요. ZIP 직접 설치는 새 설치 ZIP을 받아 기존과 같은 가져오기 화면에서 업데이트합니다. **Save Disabled Update**가 표시되면 비활성 상태로 업데이트를 저장하는 버튼입니다.

업데이트 후에는 확장이 꺼진 상태로 저장됩니다. 새 코드와 권한을 검토한 뒤 **다시 실행을 승인**하세요. 이름이 **령령의 마리나라 제작실**인 기존 확장을 업데이트하면 설정과 저장 데이터를 유지합니다. 업데이트 전에는 초안을 임시 저장하고 중요한 결과를 JSON으로 보관하세요. 화면이 갱신되지 않으면 저장을 마친 뒤 새로고침하세요.

- **v2.0.0**: GitHub 확장 관리자 설치와 수동 설치 ZIP을 제공하는 첫 공개 릴리스입니다. 캐릭터·페르소나·로어북 제작, 부분 수정, 참고 자료, 임시 저장과 라이브러리 저장 기능을 제공합니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 외부 확장 메뉴가 없거나 가져오기가 잠겨 있어요. | 서버의 `ENABLE_EXTERNAL_EXTENSIONS=true`와 위험 구역의 타사 확장 허용을 확인하세요. |
| 패키지를 찾지 못해요. | 저장소 주소를 입력하고 최상위 `manifest.json`을 선택하세요. 릴리스 ZIP을 선택했다면 저장소의 manifest 방식으로 다시 시도하세요. |
| 유령 버튼이 보이지 않아요. | 코드·권한 승인과 활성화 여부를 확인하고, 저장할 작업을 마친 뒤 새로고침하세요. |
| 요청을 보내지 못해요. | 령령 RP방이 열려 있고 AI 연결이 설정되어 있는지 확인하세요. 답변 생성이 끝난 뒤 재시도하세요. |
| 마지막 답변을 가져오지 못해요. | 최종본·수정본이 마지막 메시지인지, 선택한 제작실의 형식인지 확인하세요. 이전 답변은 복사해 직접 붙여넣을 수 있습니다. |
| 저장한 항목이 목록에 바로 안 보여요. | 진행 중인 편집을 저장한 뒤 Marinara 화면을 새로고침하세요. |
| 원본 저장이 충돌하거나 로어북 저장 결과 확인이 필요하다고 나와요. | 라이브러리의 실제 결과를 확인하고 초안을 JSON으로 보관하세요. 필요한 경우 해당 제작실을 초기화한 뒤 원본을 다시 불러오세요. |
| 팬덤 링크를 불러오지 못해요. | 사이트·네트워크 제한일 수 있습니다. 문서 본문을 직접 붙여넣으세요. |
